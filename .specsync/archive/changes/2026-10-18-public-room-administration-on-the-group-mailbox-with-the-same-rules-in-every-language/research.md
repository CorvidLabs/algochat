# Research

Identifier 0x03 was unassigned. 0x06 actions 1–4 already deliver a 101-byte membership plaintext, and 0x07 already posts one mailbox message. Those notes do not name an owner. Putting administration in the public 0x03 note, and binding key delivery to one accepted administration transaction as 0x06 action 5, leaves the older notes readable.

A request that advanced the room head would make concurrent asks stale. The request therefore does not become the head, and it must repeat the current roster.
