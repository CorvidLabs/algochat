# Local parity verification — 2026-10-18

**The tested low-level interoperability matrix passes. Full behavioral, runtime and documentation parity does not: the regressions below remain open.** These results do not support a statistical 95% correctness or release-readiness claim.

The audited candidate is **`237a97488ac663fdf326e07badc383b4452db4ad`**, tree `511fa0cbeb39127a971370008bef055ad94b2676`, the merged main checkout tested on 2026-10-18. Three workers covered language pairs; a separate reviewer checked the evidence and claim boundaries. The audit changed no library implementation or accepted Human Intent. Temporary fixture copies activated tests that otherwise skipped or returned early. This report and the portable probes preserve the findings; they do not fix them or turn the historical runs into qualification of a later commit.

## Open findings

| Finding | Reproduced result and scope |
| --- | --- |
| **Rust concurrent PSK replay** | Two synchronized calls to unmodified `receive_psk` returned duplicate plaintext in **100/100 trials**. Validation and recording use separate locks. See [source](../../rs/src/algochat.rs#L439), [independent review](2026-10-18/review.json), and the portable replay probe below. |
| **Swift PSK history disappears on refetch** | Actual public MessageIndexer/PSKManager returned one message on first fetch, zero for the identical transaction refetch, and zero after manager reconstruction from persisted state. This contradicts accepted `swift/PSK-4.c`. See [receipt](2026-10-18/boundaries/swift.json) and [source](../../swift/Sources/AlgoChat/Blockchain/MessageIndexer.swift#L450). |
| **PSK counter exhaustion differs** | Swift/Rust/Kotlin wrap to zero. TypeScript exceeds UInt32, encodes zero and cannot reopen using the wire-derived PSK. Python exceeds UInt32 and later raises `OverflowError` during encoding. Go has no managed counter/replay state; its caller supplies a UInt32 counter. This establishes counter-input reuse/range failure, not by itself nonce reuse or complete ciphertext-key reuse: fresh ECDH also contributes. See the [language boundary receipts](2026-10-18/README.md). |
| **Kotlin receive window** | A fresh state accepts counter 1,000,000; accepting UInt32 maximum resets its stored next counter to zero, then zero is accepted. This tests the low-level state method and does not claim unauthenticated high-level forged plaintext acceptance. See [receipt](2026-10-18/boundaries/kotlin.json). |
| **Rust minimum runtime fails** | Rust 1.85.0 rejects resolved `ctutils` 0.4.3, which requires 1.87. Modern 1.95 qualification passes. Compatible dependency resolution or a reviewed minimum change is still required. The original failure log is identified in the [omitted-artifact catalog](2026-10-18/omitted-artifacts.json). |
| **History ordering differs** | Kotlin sorts by timestamp/insertion rather than round/intra-round order. TypeScript's concrete AlgorandService orders tied-round offsets correctly; its exported and abstract MessageIndexer plus Conversation retain newest-first insertion in the tested tie. See [Kotlin](2026-10-18/boundaries/kotlin.json) and [TypeScript](2026-10-18/boundaries/typescript-history.json). |
| **Kotlin supplied address is not verified** | Client construction accepts an address inconsistent with the supplied test seed. Correct behavior must account for the intended signature scheme. See [receipt](2026-10-18/boundaries/kotlin.json). |
| **Minimum framing differs** | Python/Rust/Kotlin accept standard 126–141-byte and PSK 130–145-byte frames without the complete payload tag. TypeScript/Go/Swift enforce header-plus-tag minima. Later decryption rejects invalid ciphertext; this is a parser/early-rejection mismatch, not plaintext authentication bypass. See the [boundary receipts](2026-10-18/README.md). |
| **Inbound maximum is not enforced uniformly** | Tested standard/PSK parsers accept 4097-byte structures. All six low-level PQ decryptors accept a correctly authenticated synthetic 4097-byte note, returning 4003 plaintext bytes. Outgoing writer max+1 checks reject. This does not mean Algorand accepts oversized transaction notes; Go explicitly disclaims a decode-time plaintext ceiling. See the [six-reader proof](2026-10-18/boundaries/pq-inbound-all-six.json). |
| **TypeScript reply example fails compilation** | README supplies a fifth-argument ReplyContext object; the actual API takes positional transaction ID and preview, requiring 6–7 arguments. The [exact call](2026-10-18/examples/readme-reply.mts) yields [TS2554](2026-10-18/checks/readme-reply-typecheck.txt). |
| **TypeScript Node storage is not a package API** | File storage exists in source but root exports omit it; `/node` is not exported. The existing HLD already documents this product limitation. See [package check](2026-10-18/boundaries/typescript-package-exports.json). |
| **Kotlin wrapper description is inaccurate** | `gradlew` is a shell shim that executes `gradle` from PATH, ignoring wrapper 8.11 properties. Qualification explicitly used 8.14.3; default local PATH selected 9.8.0. See [shim](../../kt/gradlew) and [qualification tools](2026-10-18/qualification-catalog.json). |
| **Dashboard accepts invalid evidence** | All-zero wrong SHA/year-2000 results and an unknown status with null error each render six PASS cells. The legacy workflow also omits Go, includes archived web, has upload-path defects and infers Swift success from output. See [observations](2026-10-18/checks/dashboard.json) and [workflow](../../.github/workflows/status.yml). |

Automatic high-level PQ selection/classical fallback, account versus PSK/session recovery, platform/biometric storage guarantees, Swift fee intent versus mandatory large-note surcharge, all-six convenience APIs and independent security assurance remain unfinished or unproven. Kotlin’s blanket no-private-key-persistence requirement also needs reconciliation with its opt-in storage call. Swift PSK JSON and queued-message files contain the documented secrets/plaintext; permissions are not content encryption. Misleading “Forward Secrecy Proof” test/demo labels also remain. These findings preserve accepted goals rather than silently relaxing them.

## Reproducing the probes

Run from the repository root with the language dependencies installed. The complete six-language hybrid matrix needs macOS 26+ for Swift ML-KEM, plus Bun, Go 1.25+, a supported modern Rust, Python with ML-KEM support, JDK 17 and a suitable Gradle. Tool versions used above describe observed runs, not every supported platform. Each output directory must be new and outside the checkout.

```sh
python3 scripts/parity/mesh.py --output /tmp/algochat-parity-mesh-new
python3 scripts/parity/rust_replay.py --output /tmp/algochat-parity-rust-new
python3 scripts/parity/swift_history.py --output /tmp/algochat-parity-swift-new
```

At `237a974`, the mesh is expected to exit zero; the Rust replay and Swift history probes are expected to exit **one** after reproducing their unmet assertions. A failing regression probe is evidence of the open bug, not a passing product check. The probes generate new fixtures with public test seeds and record the actual checkout identity; they do not replay the historical LocalNet wallet. A source fix needs its own passing regressions, full relevant checks and reviewed acceptance.
