# Context

TypeScript AlgoChat is a Bun/TypeScript protocol package covering encryption, signatures, PSK ratchets, queues, storage, blockchain discovery, mnemonic accounts, and conversations. CI builds and tests it, publishes changed versions to GitHub Packages, and deploys TypeDoc through Pages. It has no prior SpecSync companions or threshold.
