## User Stories

- As a protocol maintainer, I can detect a Kotlin wire or key-derivation change that breaks any supported sibling implementation.
- As a sibling implementer, I can consume Kotlin-produced fixtures generated by production code.

## Acceptance Criteria

1. **REQ-cross-vectors-001**: Kotlin decrypts the Swift envelopes to their declared plaintext; `CrossImplTest`'s `decrypt Swift envelopes` method is the evidence.
2. **REQ-cross-vectors-002**: Kotlin decrypts the TypeScript and Python envelopes to their declared plaintexts; `decrypt TypeScript envelopes` and `decrypt Python envelopes` are the evidence.
3. **REQ-cross-vectors-003**: Kotlin decrypts the Rust and Kotlin envelopes to their declared plaintexts; `decrypt Rust envelopes` and `decrypt Kotlin envelopes` are the evidence.
4. **REQ-cross-vectors-004**: Kotlin can export its own production-generated envelope fixture in the shared schema; `export envelopes for cross-implementation testing` is the evidence.

## Constraints

- Fixtures contain deterministic test keys only and must never represent production secrets.
- Assertions must use production envelope and crypto functions.

## Out of Scope

- Network transport between language implementations.
- Publishing or versioning fixtures outside the repository's normal test artifacts.

### REQ-cross-vectors-001

The Kotlin implementation SHALL authenticate and decrypt the Swift-produced envelopes to their declared plaintext.

Acceptance Criteria
- `decrypt Swift envelopes` passes in `CrossImplTest`.

### REQ-cross-vectors-002

The Kotlin implementation SHALL authenticate and decrypt the TypeScript- and Python-produced envelopes to their declared plaintext.

Acceptance Criteria
- `decrypt TypeScript envelopes` and `decrypt Python envelopes` pass in `CrossImplTest`.

### REQ-cross-vectors-003

The Kotlin implementation SHALL authenticate and decrypt the Rust- and Kotlin-produced envelopes to their declared plaintext.

Acceptance Criteria
- `decrypt Rust envelopes` and `decrypt Kotlin envelopes` pass in `CrossImplTest`.

### REQ-cross-vectors-004

The Kotlin test harness SHALL export production-generated envelopes in the shared cross-implementation fixture shape.

Acceptance Criteria
- `export envelopes for cross-implementation testing` passes in `CrossImplTest`.
